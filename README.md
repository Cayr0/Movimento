# Movimento: controle de empréstimos

App para celular (PWA) que controla dinheiro emprestado: quem deve, quanto, vencimentos, juros, parcelas e recebimentos. Os dados ficam no próprio celular; cada pessoa pode entrar com a conta Google e guardar o backup no próprio Google Drive.

Abrir e instalar: https://cayr0.github.io/movimento/

- A raiz deste repositório é o site publicado pelo GitHub Pages (gerado, não editar à mão).
- O código fica em `codigo/`: `src/app.html` é o app inteiro; `node build.mjs` gera os arquivos do site. Detalhes em `codigo/README.md`.
